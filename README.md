### 🧑‍💻 About Me

I bridge the gap between **low-level systems performance**, **modern fullstack web architecture**, and **commercial visual design**. Whether I am writing memory-safe utilities in **Rust**, building desktop tooling in **C#** and **Python**, or architecting web applications with **TypeScript** and **Laravel**, I focus on clean execution, automation, and practical problem-solving.

- 🔭 **Currently working on:** Desktop automation utilities, containerized studio workflows, and graphics/performance QA testing.
- 🛠️ **Core Stack:** Rust, C#, Python, TypeScript, JavaScript, PHP (Laravel), Vue, and Docker.
- 🎨 **Creative & Design:** Brand Identity, UI/UX, 3D Asset Creation, and Commercial Microstock Production at **BRKH Studio**.
- ⚡ **Fun Fact:** Always down to optimize system configurations, tinker with custom audio/PC hardware, or debug tricky codebases.
